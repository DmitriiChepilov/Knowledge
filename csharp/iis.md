## Как включить «блокировку» нешифрованных запросов

1. IIS Manager → ваш сайт → SSL Settings → Require SSL (получаем 403.4).
2. (Опционально) URL Rewrite → правило «Redirect to HTTPS» (авто‑редирект).
3. (Опционально) Удалить http‑привязку в Bindings → оставить только https:443.
4. (Опционально) Включить HSTS, отключить старые TLS‑версии.
