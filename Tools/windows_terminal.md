## Разделение экрана

Для разделения экрана (панелей) в Windows Terminal используются следующие горячие клавиши:

- Верх / Низ (по горизонтали): `Alt` + `Shift` + `-` (минус)
- Лево / Право (по вертикали): `Alt` + `Shift` + `+` (плюс)

Управление панелями:

- Перемещение между панелями: `Alt` + клавиши со стрелками.
- Изменение размера: `Alt` + `Shift` + клавиши со стрелками.
- Дублирование текущей панели: `Alt` + `Shift` + `D`.
- Закрытие активной панели: `Ctrl` + `Shift` + `W`.

More information see in the article [Panes in Windows Terminal](https://learn.microsoft.com/en-us/windows/terminal/panes)
