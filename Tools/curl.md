## Checking proxy and site

```sh
curl.exe -v -L "https://site.com" --proxy "http://user:***@proxy.company.com:8080"
# or
curl -v -x http://proxy.company.com:8080 -U 'user:pass' https://site.com #not_a_secret
```

| Параметр                 | Что делает                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| `-v` (verbose)           | Показывает запрос, заголовки ответа, статус‑код, а также любые сообщения об ошибках.      |
| `-i`                     | Если хотите видеть только **заголовки** вместе с телом (полезно, когда тело пустое).      |
| `-L`                     | Автоматически следует по редиректам.                                                      |
| `--trace-ascii curl.log` | Записывает весь обмен (включая бинарные данные) в файл `curl.log` для детального анализа. |
